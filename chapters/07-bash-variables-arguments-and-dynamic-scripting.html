Bash Variables, Arguments and Dynamic Scripting

Pass data into scripts and shape commands at runtime with variables and arguments.

3 min read 3 sections 7 code blocks Chapter 07 / 30
Next chapter

Why Use Variables?Real Use CaseLet’s say you want to:

To go beyond static scripts, you must master variables and arguments in Bash. These tools turn one-off commands into scalable, repeatable, dynamic payloads and automation tools.

Why Use Variables?#

Variables allow you to store data (like usernames, ports, IPs, payloads) and reference them throughout your script.

Example:

bash
name="CyberSec"
echo "Welcome, $name!"

Script Arguments: $1, $2, $@ When running scripts, you can pass in values externally:

bash
#!/bin/bash
echo "User: $1"
echo "Password: $2"

Run with:

text
./login.sh admin admin123
Symbol Meaning
$1 First argument
$2 Second argument
$@ All arguments

With Loops Example script: multi_ping.sh

bash
#!/bin/bash
for ip in "$@"; do
  echo "Pinging $ip..."
  ping -c 1 $ip
done

Run it:

text
./multi_ping.sh 192.168.1.1 192.168.1.2 192.168.1.3

Practice Task Build a script called enum.sh:

bash
#!/bin/bash
target=$1
echo "[*] Running scan on $target"
nmap -Pn -sS $target

Make it executable:

bash
chmod +x enum.sh
./enum.sh 10.10.10.10

Extend it to accept port ranges or scripts

Real Use Case#

Let’s say you want to:#

  • Auto-recon targets from a list
  • Brute-force web login pages
  • Drop backdoors on multiple IPs
    With $1, $2, $@, and for loops - your Bash script becomes multi-target, adaptable, and scalable.
